# milvus
项目文档智能检索系统
项目简介

这是一个基于 Zilliz (Milvus) 和 LangChain 的智能文档检索系统，专注于高效处理项目相关的设计文档。系统支持将项目文档转化为向量，并进行语义检索和问答。通过该系统，用户可以基于自然语言问题查询相关项目文档，快速获取准确的信息。

主要功能

文档上传与存储：上传项目设计文档并将其转化为向量，存储于 Zilliz 集群。

语义搜索与问答：支持基于自然语言输入的问题进行文档检索和问答。

项目管理：每个文档与项目名称和项目编号关联，便于组织和管理。

高效向量搜索：基于 Zilliz 集群进行高效的文档检索。

项目元数据管理：自动提取项目元数据（如项目编号），便于进一步查询和筛选。

系统架构

Zilliz 集群：用于存储和管理文档数据，并支持高效的向量检索。

LangChain：用于构建问答系统，实现文档的语义搜索。

Vector Search System：用于将文档内容转化为向量并存储，进行快速检索。

使用流程
1. 上传文档

用户可以通过 Web 界面上传项目文档。每个文档将自动与一个项目名称和编号进行关联，并被转化为向量存储在 Zilliz 集群中。上传的文档会自动进行文本处理，并且可以在后续的检索中被使用。

2. 查询文档

用户可以通过输入自然语言查询来获取相关文档的内容。例如，用户可以输入“项目A的设计文档”，系统会自动进行向量检索，并返回与输入查询最相关的文档内容。

3. 配置查询

用户可以进一步配置查询条件，指定项目名称或其他元数据，来帮助精确地筛选结果。这些查询参数会直接影响系统的检索结果，确保返回最相关的文档。

数据存储
Zilliz 集群

文档数据被存储在 Zilliz 集群（基于 Milvus）中，存储时将文档的文本内容转化为向量，并结合项目名称、编号等元数据进行索引，方便后续的高效检索。每个文档存储的信息包括：

项目名称：关联文档所属的项目。

项目编号：文档对应的项目编号。

文档内容：存储文档的实际内容。

文档类型：例如设计文档等（目前仅支持设计文档）。

上传时间：文档的上传时间，用于排序和筛选。

向量存储与检索

每个文档被转化为向量，并使用 Zilliz 集群进行高效的检索。用户查询时，系统将输入的查询转化为向量，然后与文档向量进行比对，返回最相似的文档。
